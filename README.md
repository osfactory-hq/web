# osfactory.net

Web pública de OS Factory. Página estática (HTML, CSS y JavaScript en un solo archivo), sin cookies ni herramientas de seguimiento.

## Contenido

- `index.html`: la página, en español e inglés.
- `privacidad.html`: política de privacidad, en español e inglés.
- `og.jpg`, `apple-touch-icon.png`, `favicon.ico`: imagen para compartir el enlace e iconos.
- `fotos/`: fotos de Unsplash (licencia Unsplash, uso comercial permitido), en JPEG y en WebP a varios tamaños.
- `fonts/archivo.woff2`: tipografía Archivo, alojada aquí para no cargar nada de terceros (licencia SIL OFL, en `fonts/OFL.txt`).
- `CNAME`: dominio propio para GitHub Pages.
